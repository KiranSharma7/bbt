Find Your Way In

Five structures for the same section. Same visual system, same catalogue, same working filters — only the shape of the browsing experience changes.

  1. 01 Ruled Counter Filters as two ruled counter bands under the headline, Thai set four times larger than its siblings, over a four-column book table. Closest to the approved reference layout. Language + topic bands 4-column table Live tallies →
  2. 02 Ledger Rail Language chosen from a shelf of upright spines beside the headline; topic kept in a stationer's ledger down the left, each line ruled with its tally. Adds sorting and removable chips. Spine rack Sticky topic rail Sort + chips →
  3. 03 Language Spine The language filter drawn as a shelf seen edge-on. Five upright spines, Thai widest; choosing one lifts it out of the row. Topics run below as a ruled tab strip. Vertical spines Topic tabs Most expressive →
  4. 04 Contact Sheet The densest of the five and the only one with search. Covers printed as numbered frames on a photographer's contact sheet, six across, caption underneath. Live search 6-across Fastest to scan →
  5. 05 Split Board The only one that answers rather than lists. The first match is promoted to a full display with its own call to action; the rest stay as a compact ruled index beside it. Promoted pick Running index Best for newcomers →

All five run on the same preview catalogue. Thai prices and availability are confirmed from the discovery document; other-language titles, prices and stock are placeholders, and every cover is an English-edition scan standing in until Thai artwork is supplied.
