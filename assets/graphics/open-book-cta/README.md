# Open Book CTA asset pack

These assets recreate the selected open-book composition while leaving all
headlines, supporting text, and buttons semantic in HTML.

## Assets

- `open-book-frame.svg` — transparent upper/lower page curves and center fold.
- `center-rule.svg` — the horizontal hairline and centered diamond.
- `page-tabs.svg` — the complete five-step brand ladder as book-page tabs.
- `book-bhagavad-gita-open-door.png` — angled transparent book mockup.

The book preserves the exact artwork from `assets/books/en-bg.jpeg`. Only the
physical board, Thai-red spine, page edges, rotation, transparency, and warm
book-only shadow were added.

Layer the frame above the page background, place the tab stack at the left edge,
render HTML content over the center, and crop the book through the lower-right
edge on desktop. Reduce or remove the book before shrinking content on mobile.
